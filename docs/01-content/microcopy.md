# Microcopy

Short text tied to actions and controls. Voice: `tone-of-voice.md`. Formatting: `writing-style.md`.

## CTAs (button labels)

CTAs are about action. They move work forward: assigning, submitting, uploading, closing.

- Use clear, specific verbs that match the task.
- Keep it to **1 to 3 words**.
- Use Title Case (not stated as a rule in the source; every source example is Title Case).
- Avoid vague language such as "Click here".
- Avoid overly casual phrases such as "Let's go!".

| Correct | Incorrect |
|---|---|
| Edit Room | Click here |
| Assign Users | Let's go! |
| Save Changes | |

For which button style to use (primary, destructive, etc.), see `04-component-guidelines/actions.md`.

## Tooltips

- Contain relevant, specific content.
- Never hold essential task instructions: a tooltip is not persistent, so the user may never see it.
- Icon-button tooltips: **no more than 3 words**, describing the button's function.

## Checklist

1. Does the label start with a verb that names the outcome?
2. Is it 3 words or fewer?
3. If it's a tooltip, can the task be completed without ever reading it?
