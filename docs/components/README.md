# Catálogo de componentes (Storybook RestorNet)

El Storybook de RestorNet define **qué componentes existen**. Las guías Solar de `docs/0*`
definen **cuándo y cómo usarlos**. Esta tabla une las dos cosas: para cada componente del
Storybook, qué guía leer y en qué estado de diseño está en Figma.
Regla de uso: `.claude/rules/storybook-components.md`.

Columnas:
- **Variantes en Storybook:** las stories publicadas, que sirven de referencia visual y de props.
- **Playground:** archivo que probablemente lo implementa (supuesto por nombre, confirmar
  contra el Storybook). `—` = todavía no existe.
- **Guía de uso:** archivo de `docs/04-component-guidelines/` (u otra carpeta) y sección.
  `(?)` = el nombre del Storybook no coincide con el de Figma y la relación es supuesta;
  confirmarla con el equipo de diseño. `sin guía` = las guías no cubren ese componente.
- **Estado Figma:** de `docs/06-governance/design-status.md` (snapshot 2026-11-19). Si no es
  Approved, la guía es provisoria: avisar al usarla.

Generado desde `index.json` del Storybook el 2026-11-18.
